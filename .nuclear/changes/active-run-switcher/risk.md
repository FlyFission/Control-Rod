# Active run switcher risk

## Selected mode

- **Mode:** Standard

Scope is the existing active run read, shell navigation and exact package run detail. The list must apply organization ownership before limiting the result set. A route for a missing run must show unavailability and stay away from other attempts. Stream drops and refresh failures must indicate stale data. Existing run and human decision behavior remains authoritative.
