Claim: four statements, one per bullet.
- `daemon/internal/battlescars` provides `SanitizeExternalText` (stripping `<ao-standing-instructions>`, `<ao-worker-reports>`, `<system-reminder>`, and `<pasted_content>` blocks, unclosed openers/closers, ANSI escapes, and ASCII/Unicode control characters, while truncating on valid UTF-8 rune boundaries within `maxBytes`) and `SafeCollisionFilename` (appending `-1`, `-2`, ... before the file extension while enforcing the 255-byte `NAME_MAX` budget on valid UTF-8 rune boundaries and rejecting path separators or control characters).
- `daemon/internal/battlescars` provides `IdempotentStopTracker` (concurrency-safe turn-scoped `(sessionID, turnID)` stop coordination that signals only on the first call and suppresses duplicate requests or requests against waking/archiving sessions) and `BoundedDeliveryBudget` (quarantining undeliverable items as `DeliveryDeadLetter` once `MaxAttempts` or `MaxAge` is exceeded, and preserving `DeliveryAcked` once acknowledged).
- `daemon/internal/battlescars` provides `ResolveAuthStateOnError` (preserving `prevKnownGood` across transient `os.ErrDeadlineExceeded`, `syscall.EIO`, `syscall.EACCES`, `syscall.EBUSY`, and context cancellation/deadline failures while clearing auth on explicit `probeErr == nil && !probeAuth` rejection) and `NormalizeUTCTimestamp` (rejecting naive timezone-less strings and normalizing RFC3339/RFC3339Nano timestamps to `2006-01-02T15:04:05.000Z` where lexical order matches chronological order).
