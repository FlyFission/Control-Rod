## Claim proven

Claim: five statements, one per bullet.
- `daemon/internal/artifactstore` enforces `os.OpenRoot` confinement, SHA-256 content addressing, size caps, corruption detection, and two-poll `StabilityTracker` semantics under `-race`.
- `daemon/internal/filesnapshot` captures hidden refs via disposable `GIT_INDEX_FILE` without touching branch, real index, or stash, refuses nested repositories, enforces untracked caps, and verifies `PlanID` and `BeforeRollbackRef` on `Apply` under `-race`.
- `daemon/internal/pricing` verifies SHA-256 digests, rejects unknown JSON fields and malformed decimals, computes exact `*big.Rat` costs with deterministic `OverrideVersion`, and uses zero floating-point types (verified via `go/ast`) under `-race`.
- `daemon/internal/scmobserver` enforces immutable `(Provider, RepoID, PRID)` keys, positional batch attribution, two-phase semantic hash acknowledgement, terminal PR eviction, current-`HeadSHA` check reduction (`CANCELLED` as failing), and controller-only GitHub Check Run binding under `-race`.
- Originality, public-claims, whitespace, trust-surface diff, and `ng.py validate` checks pass.
