- E-03: `node --test scripts/test/doctor.test.mjs` 11 pass; the placeholder test failed before the `${me}` fix.
- E-04: the `product` steps, run as the ordinary user `claude` on a copy of this branch with a separate home and port: install, link, start, `/health`, the page, status, stop.
- E-05: as root and as the ordinary user `claude`, with `TEST_DATABASE_URL` unset, `tools/test-api.mjs` chose the bundled PostgreSQL and the API tests passed, with the rehearsal skipped and said so. With no usable PostgreSQL and no `flex`, it named `flex` and downloaded nothing. After the first CI run on PR 260 (the runner's Ubuntu 26.04 image has a PostgreSQL 18 server, which the bootstrap picked while CI gave PostgreSQL 17 client tools, so `pg_dump` refused mid-test): with `CONTROLROD_TEST_PG_SERVER=bundled` the bootstrap picks the bundled server and tells the harness; stand-in client tools reporting 18, and the host's 16, are refused before any test runs with a plain message; run through vitest directly, the rehearsal's own check refuses 18 before it starts; stand-in tools reporting 17 pass both checks. Real PostgreSQL 17 client tools could not be installed on this machine (apt.postgresql.org is not reachable from it), so the rehearsal itself was last run by CI.
- E-06: `scripts/build-kernel-wasm.sh` with wasm-bindgen-cli 0.2.104 rebuilt the committed files byte for byte, also with a different cargo home; without the path mapping that build differs.
- E-07: `cargo test --locked`, `cargo clippy --all-targets -D warnings` and `cargo fmt --check` pass; `transition_table` 3 pass; the WebAssembly table test 3 pass; each fails when one row of the table is changed.
- E-08: `go test -race ./...`: no data race. One test failed, `TestAuthorEgressFilterStartsAndInjectsProxyEnvDuringRun`, because this machine sets `YARN_HTTPS_PROXY`; it is the known environmental failure fixed in PR 253, and it fails the same way without `-race`.
- E-09: `pnpm spec` leaves `spec/generated`, `daemon/internal/wire/schemas` and `services/api/src/preparation/schema.d.ts` unchanged.
- E-10: workflow diff reviewed; `uv run --no-project --with pyyaml==6.0.3 python tools/check_redteam.py` passes.

## Exit criteria

CI installs and starts Control Rod as an ordinary user and checks that it answers and stops; rebuilds the WebAssembly kernel and fails on any difference; runs the repository's own checks, the doctor tests, the kernel decision table in Rust and WebAssembly, and the daemon tests under the race detector; and runs the API tests on the bundled PostgreSQL without compiling one. Every gate that failed on main passes, and no gate is weakened. The owner signs the `.github/` and other trust-surface changes before merge.
