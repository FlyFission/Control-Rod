Codex (gpt-6.2-astra) blind review round 1 on head 62a0b653 asked for changes: 3 privacy blockers (free-text label, plan and version fields), 8 majors (child environment, cache file handling, Codex log reading on the claim path, process-group cleanup, provider deadline and starvation, a malformed report replacing a good one) and 2 minors (reorder without drag, pace time). All 13 were fixed with regression tests; labels were removed from the contract, plan is a closed list and version a numeric pattern.

Round 2 on head 2323debf asked for changes with no blockers: claim path could still block on disk, shutdown did not reach a CodexBar refresh, a malformed report could still replace a good one, Claude windows shared one observation time, Codex picked a rollout by creation name, plus three minors (missing percent read as zero, loose timestamps, drag pointer capture). All fixed with regression tests. The note that the Codex reader reads raw log tail bytes into memory before filtering is recorded in ADR 0025 decision 1 rather than changed.

Round 3 on head 34351114 found no privacy path and no blockers; 4 majors and 3 minors on edge cases (process-group kill after reaping, persistence goroutine backlog, a "none" provider with invalid windows passing validation, a completed fetch with no reading keeping the old one, same-second Codex ties, a stale-only headline, timestamp years). All fixed with regression tests except pgid reuse, which cannot be triggered deterministically; it now uses the package's wait-without-reap mechanism.

Round 4 on head 691efbed found no blockers; 2 majors and 1 privacy minor. Majors: a wait failure reaped the child before the group kill, and the 30-minute keep-previous used the upstream time and was not enforced between refreshes. Both fixed: the group is killed before a single reap, and each provider now carries a local expiry (fetch time plus 30 minutes, only shortened by an older upstream time, future times clamped) checked at every snapshot, with three regression tests. The privacy minor repeats the round 2 note on the Codex log tail and is left for the owner to decide.

Round 5 on head 98f9f6b3 returned VERDICT: MERGE. Codex confirmed both round 4 fixes by static review (group kill before the single reap; local expiry enforced at every snapshot) and found no blocker, major issue or new privacy path. Codex did not rerun tests.
