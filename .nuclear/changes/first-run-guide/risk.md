# Risk: A guided first run on the board

- A step could read done when it is not, or the reverse. Each is derived from a server read the board already makes (or the per-user project list); the guide never blocks anything, so a wrong tick costs a moment, not work.
- Three more reads on the board (runtimes, subscriptions, setup). They are the Setup page's reads and are cached.
- No trust surface is touched.

## Selected mode

- **Mode:** Standard
- Basis: web-only change, reversible by revert, no trust surface.

## Required links

[Risk](risk.md), [basis](basis.md), [plan](plan.md), [trace](trace.md), [verification](verification.md), [ship](ship.md).

## Exit criteria

A new person on the board sees five steps from choosing agents to an accepted change, each ticked from real state, with one primary button for the next step only; the guide closes when a change is accepted or the person hides it. Web tests and typecheck pass.
