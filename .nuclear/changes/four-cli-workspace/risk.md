# Planning and qualification risk

## Selected mode

- **Mode:** Standard

This record covers a plan and its advisory review. A later implementation changes run retrieval and provider eligibility. Historical run evidence must bind the exact attempt. Each additional provider needs its own scoped qualification record. Preserve all existing launch and review refusals through that work.
