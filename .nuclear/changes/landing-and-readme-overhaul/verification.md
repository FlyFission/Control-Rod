## Independent review before merge (2026-11-24)

Two reviewers separate from the authoring session read the diff against `main`: a Claude review session and a Codex blind check (`codex exec -s read-only`, run on the owner's machine in a throwaway clone). Findings fixed on the branch:

- `controlrod check` examples used `--checker-runtime` and `--format`; the CLI takes `--checker` and `--output` (reproduced: exit 2). Examples now build with `go -C daemon`, need Go 1.24 (`daemon/go.mod`), and use inline criteria instead of a file that does not ship.
- Research copy now matches `docs/research/second-checker/inputs.json`: METR's 296 is all reviewed AI PRs and "roughly half" is of the test-passing ones; Laban's 39% is a performance drop; Sharma's 98% is Claude 1.3 conceding when challenged. `evidence-board.svg` regenerated by `build.py`.
- Receipt copy says what `pnpm cr verify` proves (receipt matches the sealed bundle; seal key ownership is not checked offline) and the site demo is labeled as a sample.
- `--criteria-ref` is described as opt-in for the CLI; the Action's prerequisites (checker CLI installed and signed in on the runner) are stated.
- `serve-site.mjs` binds to loopback, returns 400 on malformed URLs, and checks the real path of every file against `site/dist`; `build-site.mjs` copies link targets, not links, and detects direct runs with `pathToFileURL`. `site/index.html` carries the CSP as a meta tag for static hosting.
- README opening states the two passkey gates instead of "every state transition"; the 200-perspective study is labeled a scripted rubric over modeled personas.

The asset digests in `evidence/assets.sha256` are a point-in-time record from the authoring session; the readme-shots workflow and the regenerated SVG have since changed some of those files.
