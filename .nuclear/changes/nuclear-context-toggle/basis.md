# Basis: per-card Context Light / Nuclear toggle

**Change slug:** `nuclear-context-toggle` (replaces the records `nuclear-context-brief` and `nuclear-grade-pack`)
**Related risk record:** `risk.md`
**Owner:** Ben Huffer
**Date:** 2026-11-21
**Decision this basis supports:** whether a card may run under a Light or Nuclear context profile, with Nuclear briefs carrying the generated nuclear-grade pack's cards.

## Need

BRIEF.md is the only instruction an agent gets. Some work needs the nuclear-grade discipline (Core card, cluster cards); most does not and should not pay for it in context. A per-card switch with a project default gives the choice to the person; Safety and Material grade work has no choice.

## Design

- **Contract.** Optional `WorkPackage.context_profile` and `Project.default_context_profile` (`light` | `nuclear`), migration 024.
- **Resolution** (`resolveContextProfile`): Safety or Material grade locks Nuclear; else the card's value, else the project default, else Light. The web helper `apps/web/src/lib/context-profile.ts` mirrors it for display, with the same reasons; the server decides.
- **Composer.** `selectClusters` picks clusters from structured facts by one table; `nuclearBriefSections` puts cards inline and ships full skills and templates as inputs. `buildJob` composes BRIEF.md through the pure `composeBrief` in `services/api/src/brief.ts` and records `run.context-profile` for Nuclear runs. `loadNuclearPack` reads only files whose real path is under the pack's real path and whose sha256 matches `manifest.json` `files`; when a Nuclear run's pack is missing or fails, the claim fails the queued run before launch (label "Not started", the reason as its error) and the event records the problem. hygiene and incident-deficiency stay in the pack but are not selectable yet: no declared WorkPackage field says when they apply (follow-up). The board's switch is read-only for a draft in guided preparation, which refuses the plain draft edit.
- **Pack.** `packs/nuclear-grade/` is generated by `scripts/generate-nuclear-pack.mjs` from NGCE at `395aa6e`; `--check` fails on hand edits. `budgets.json` is the one pack file not from NGCE: the generator keeps it and `--check` skips it.
- **Budgets.** `scripts/measure-briefs.mjs` composes Light and Nuclear briefs for four fixture packages with the API's own pure functions, counts BRIEF.md with `scripts/lib/token-count.mjs`, and writes the counts, inputs and an inputs sha256 to `budgets.json`. Budget = measured; no number in it is typed.

## Not done

- The trust-surface path rule is not applied: the WorkPackage contract has no path scope. `TRUST_SURFACE_PATHS` documents the list for when `spec/` adds one.
- ADR 0002 places discipline packs in a private repository; this public MIT pack is in the public repository by instruction. Open for the owner.
