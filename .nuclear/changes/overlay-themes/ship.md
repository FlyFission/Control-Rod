# Handoff posture: overlay themes

Date: 2026-10-25. Delivery scope: proposed full specification, art-production catalog and implementation plan.

This packet is ready for review after the documented checks. No product code, final artwork, tested theme renderer, approved public influence label or rights-cleared franchise pack is delivered. No push, pull request, merge or deployment is performed. Existing old change records' publication/execution permissions are not reused.

Proposed defaults to review: Floor-only scope, original public identities with strong influence lineage, six unnamed variants per pack, no runtime pack imports, fixed shared stations, native SVG/CSS, browser-local settings, static previews, visible package paging, and staged launch with Plain Floor escape. Fifteen is the full catalog target; each production pack needs artwork and its own release evidence.

Implementation can start when the user requests it against a reconciled executable baseline. Native sequential execution is a sensible proposed default; no execution method has been selected. Only a new need to touch protected surfaces would trigger AGENTS.md's specific authorization rule; the proposed frontend work does not require inventing one.

Documentation rollback removes the new packet/spec/catalog/plan and the docs-index entry. Product rollback is separately planned via feature flag, pack allowlist and rebuild; no domain-data rollback is required.
