Control Rod v0.1.0. First release. Pre-alpha and owner-local: one machine, one person.

Not in this release: phone approvals, and remote daemons over SSH. ADR 0024 decision 5 keeps both planned. Phone approvals follow this release. Remote daemons stay in the plan and are not in this tag.

macOS: expected to work, not yet verified live. Agent launches on macOS are qualified in scripted CI only. Live login is verified on WSL2.

Install: clone, mise install, pnpm install, pnpm cr doctor, pnpm cr start.
