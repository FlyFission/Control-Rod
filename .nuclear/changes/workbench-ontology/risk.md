# Risk: workbench and ontology

- **Mode:** Standard
- Standard-plus routing: the change defines new controlled object types, the action catalog, decision subjects that include sandbox attestation, and protected kernel rules.
- Execution owner: Claude Code under the owner's 2026-10-29 instruction to specify and review.
- Decision owner: repository owner; no protected surface signature inferred.
- Mission: give Control Rod's existing trust controls a first class experience, borrowing commodity mechanisms without importing other products' trust gaps.

| Risk | Control | Stop condition |
|---|---|---|
| Themes drift from the office or alter meaning | Inert scene data under an application owned semantic layer; validator and harness before the renderer; two themes from the first commit | A theme renders a mark, label or control, or an office change ships without passing both themes |
| Collage of donor products instead of one design | Ontology first; P10 borrow plumbing only; every screen a projection | A screen adds a write path outside the action catalog |
| License contamination | Pinned donors, file level license check, borrowed code register, ideas only list | A ported file lacks a register entry or has a non permissive effective license |
| Clean room breach | Builders never open Kandev material; notes need a wording check | Kandev text or structure appears in the repository |
| Live sessions erode the promise path | Freeze rule N-5; controlled runs cannot be typed into | Exploration output reaches acceptance without a headless rerun |
| Overclaiming isolation | Honest flags, attestation, WB-00 wording fix | Copy claims a sandbox, witness or compliance not evidenced |
| Protected surfaces changed without signature | Plan marks them; unsigned proposal first, signature before any edit | Any edit to a kernel decision function, policy, red team fixture or CI file before the owner's signature |
| Outside reviewers see repository content | Owner authorized the four CLIs; only the spec, plan, donor register and packet are sent | Any secret, client or restricted lane content in the review bundle |

No deployment, release or engineering acceptance is authorized by this record.
