    - Deterministic computation command (`AGENTS.md` Rule 5): generates `evidence/job-times.txt` from `evidence/job-times.raw.json`.
      ```bash
      python3 - <<'PY'
      import json
      from datetime import datetime
      from pathlib import Path

      evid = Path(".nuclear/changes/xerj-patterns-and-timeout-guard/evidence")
      data = json.loads((evid / "job-times.raw.json").read_text())
      run_id = data["run_id"]
      caps = {"typescript": 20, "rust": 30, "go": 15, "python": 15, "licenses": 15, "change-records": 10, "sbom": 10}
      rows = []
      for j in data["jobs"]:
          secs = int((datetime.fromisoformat(j["completed_at"]) - datetime.fromisoformat(j["started_at"])).total_seconds())
          cap = caps[j["name"]]
          rows.append((j["name"], secs, cap, cap * 60 / secs))
      rows.sort(key=lambda r: (-r[1], r[0]))
      min_row = min(rows, key=lambda r: r[3])
      rust_secs = next(r[1] for r in rows if r[0] == "rust")
      lines = [
          f"Control Rod CI, per-job wall time from the check runs of run {run_id}",
          "(pull_request, head 37f1ab8, 2026-11-06). Time is started_at to completed_at",
          "of each check run, so it includes runner setup and tool installs. One run.",
          "",
          "job             seconds   proposed cap   cap / measured",
      ]
      for name, secs, cap, ratio in rows:
          cap_str = f"{cap} min"
          lines.append(f"{name:<16}{secs:<10}{cap_str:<15}{ratio:.1f}x")
      lines += [
          "",
          f"Caveats: one run, with warm tool caches (rust at {rust_secs} s is likely faster than a",
          "cold-cache build). Proposed caps are owner policy choices, not derived",
          f"measurements; the smallest margin in this run is {min_row[0]} at {min_row[3]:.1f}x.",
      ]
      (evid / "job-times.txt").write_text("\n".join(lines) + "\n")
      PY
      ```
