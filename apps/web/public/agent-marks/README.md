# Agent marks

The product marks shown on agent seats, the agents roster and the workflow diagram.

| File | Product | Owner |
|---|---|---|
| `claude.svg` | Claude Code | Anthropic |
| `codex.svg` | Codex | OpenAI |
| `agy.svg` | Antigravity | Google |
| `grok.svg` | Grok | xAI |
| `opencode.svg` | OpenCode | the OpenCode maintainers |
| `ollama.svg` | Ollama | Ollama |

The vectors come from [Lobe Icons](https://github.com/lobehub/lobe-icons) (`@lobehub/icons-static-svg` 1.106.0, MIT, Copyright (c) LobeHub), copied unchanged apart from the fixed `1em` width and height and an inline layout style, which the app sets instead.

The names and logos are trademarks of their owners. Control Rod shows them only to say which product sits in a seat. Control Rod is not affiliated with, sponsored by or endorsed by any of them. Marks are drawn in their owners' colours; the single-colour marks are drawn in black or white, as their owners ship them. An owner who wants a mark changed or removed can open an issue, and it is one line in `apps/web/src/lib/agentMarks.ts`.
