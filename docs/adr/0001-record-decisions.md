# ADR 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-22

## Context
Control Rod must be qualifiable as quality-affecting software, so every design choice needs a traceable rationale.

## Decision
Every significant decision is a numbered record in `docs/adr/`. A record is accepted only by a signed commit from a maintainer who did not author it. Superseded records stay, marked with the record that replaced them.

## Consequences
The design description of the SQA package is assembled from these records.
