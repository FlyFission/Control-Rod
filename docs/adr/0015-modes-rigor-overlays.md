# ADR 0015: Modes, rigor tiers and QA overlays

- Status: Accepted
- Date: 2026-10-22

## Decision
One control spine serves two modes, Software and Capital Projects, each a domain pack. Rigor tier (administrative, quick, standard, high-consequence) and QA overlays (for example NQA-1, ISO 9001, 21 CFR Part 11) are independent settings. Overlays add floors; they never remove them.
