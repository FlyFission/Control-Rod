# ADR 0018: CADCraft as the drawing engine

- Status: Superseded. Withdrawn 2026-11-06 by the owner: CADCraft and the drawings pack were removed with the site-concept pack
- Date: 2026-10-22

## Summary
This record had proposed CADCraft, driven headless inside the sandbox, as the engine that renders every drawing sheet from a template and a record, so agents never draw borders or type title blocks. Nothing in Control Rod depends on it now; the record stays so ADR numbering is unchanged.
