# One spine, two modes

Engineering is the umbrella. Software engineering and capital project engineering are the two modes under it, sharing the same controls.

| | Software mode | Capital Projects mode |
| --- | --- | --- |
| Unit of work | A change (pull request) | A deliverable revision (document number and revision) |
| Register | Backlog of issues | Master deliverables list |
| Inputs | Issue, specs, codebase | Design basis, controlled inputs, codes and standards |
| Machine evidence | Tests, types, lint, security scans, CI | Execution traces, reproducible calc runs, unit and clash checks |
| Independent check | Review agent plus code owner | Checker, alternate calculation, design review, interdiscipline check |
| Human decision | Approve the pull request | Approve for issue; professional seal where required |
| Release | Merge and deploy | Issue for review or approval, with transmittal; construction issue stays outside Control Rod |
| Change after release | New pull request or revert | New revision with clouded changes and revalidation |
| Interfaces | API contracts | Discipline parameters with deadbands |
| Cadence | Continuous | Phase gates (FEL-1 through detailed design) |

Shared by both: work packages, agent baselines, sandboxed runs, execution traces, evidence custody, independent verification, signed decisions, organization floors, rigor tiers and QA overlays.
