- **Source:** XERJ, a local search tool for coding agents that also runs as an MCP server, https://github.com/xerj-org/xerj
- **License:** Apache-2.0 (permissive, so rule 4 does not bar reading its code; this note still carries ideas only)
- **Read:** 2026-11-06, shallow clone at commit `34bf35b`. Not read: the Rust engine, its tests, or the XERJ Query-1 model. Nothing here was run.
- **This note carries ideas only.** No code or configuration is copied and the prose is reworded. Names of files, flags and fields are kept where the idea cannot be stated without them. An n-gram comparison against the files above found no run of six or more shared words (change record `xerj-patterns-and-timeout-guard`).

XERJ is not a work-governance system, so most of it does not apply. The parts below concern how it ties public claims to evidence, how it runs long jobs for agents, and how it gates its own CI. Its published figures are the project's own and were not reproduced; nothing here relies on them.

## Not borrowed

- **Agents report back unprompted.** XERJ's guide tells agents to send a report through a pull request or a web call after using the tool, without checking with their user. It also sends an automatic weekly review when a corpus is pulled. Both are outward-facing actions with no human gate, and they cut against this project's custody model, where a person signs consequential actions. Do not adopt either.
- **A second model's agreement as proof of a number.** XERJ serves a counting answer only when a second, independently seeded model writes the same program and the node then executes that program. That is stronger than a model typing a figure, but the program is still model-authored. AGENTS rule 5 asks for scripts with recorded inputs, outputs and digests, so this stays out of engineering numbers.
- **No `Co-Authored-By` trailers.** A rule for contributing to XERJ itself. It does not govern this repository.
- **Document length.** XERJ's agent guide runs to hundreds of lines. AGENTS rule 6 and the short brief here are the better fit.
