# Fifteen-world catalog and art-production specification

Date: 2026-10-25. Status: proposed art briefs; every title is a working title and every pack starts **development**. No artwork, trademark clearance or license is supplied by this document.

Read with the [engine specification](2026-10-25-overlay-themes-design.md) and [implementation plan](../plans/2026-10-25-overlay-themes.md). Franchise references below are explicit **creative lineage**, not approved public branding, permissions or an instruction to copy protected expression. Public influence notes are optional and separately reviewed. Recognition through atmosphere is a goal; exact source recognition is not an acceptance test that overrides distinct original expression.

## Shared art recipe

Every pack supplies one scene, six ordered character variants, up to six reusable prop assets, a thumbnail, descriptor, editable source and asset/rights manifest. See engine section 6 for dimensions, byte budgets, passive-SVG rules and common action treatments. Six variants do not cap the number of agents. Stable run badges distinguish repeated variants.

Every scene places these semantic stations in the existing floor's corresponding zones: **general** (upper left), **site** (upper middle), **archive** (upper right), **verify** (lower left), **office** (lower middle), **bench** (lower right). Pack-specific station names below are decorative nicknames, not replacements for canonical labels. Keep task labels on quiet backplates. No scenery may conceal a slot, focus ring or request marker.

Characters share a foot anchor but not a body template: mix silhouettes, material, proportions and tools. Each supports shared work/inspect/wait/attention/submitted/error treatments. Eyes, gestures and held tools should read at scene size. No visual disability, species, costume or character variant encodes actual model quality, permission, competence or task success.

Each signature below uses one existing shared primitive; a unique illustration and palette provide the difference. Effects occur only on observed submission and never indicate that human approval happened. Accepted packages get the shared static archive seal. No random deliveries masquerade as real outputs.

### Production waves and coverage

| Wave | IDs | Distinct experience tested |
|---|---|---|
| A | `creature-dispatch`, `pocket-lab` | Creature silhouettes, mechanical workers, busy but readable scenes |
| B | `midnight-bureau` | Human silhouettes, restrained motion, premium dark scene |
| C | `confectionery-works`, `lanternwood-guild`, `corner-cafe`, `tumbletown-workshop` | Fantasy, domestic warmth and hand-drawn whimsy |
| D | `orbital-shipyard`, `wildlight-camp`, `voxel-foundry` | Sci-fi, creature variety and geometric construction |

## 1. The Monster Mailroom

- **Genre:** friendly monster workplace ensembles; a busy dispatch floor run by gentle creatures. Wave A. ID `creature-dispatch`.
- **Emotional target:** a bustling, warmhearted creature workplace; capable workers with comic physical variety.
- **Composition/materials:** stepped parcel depot, frosted capsule tubes, ceramic counters, ribbed metal, soft overhead pools of light. Emphasize parcel routing; avoid any apparatus or set piece recognizable from an existing work.
- **Art swatches:** seafoam `#78C5AF`, plum `#60476E`, butter `#F4D79A`, ink `#20323D`. Functional text contrast is checked separately.
- **Cast order:** broad moss-furred courier; tall velvet moth clerk; squat stone sorter; long-necked feather archivist; round many-footed mechanic; small fin-eared inspector. Original faces and proportions; no likeness of any existing character, costume or insignia.
- **Stations:** dispatch desk / fabrication dock / parcel archive / inspection counter / supervisor window / waiting platform (order: general/site/archive/verify/office/bench).
- **Props:** parcel capsule, routing card, desk stamp, trolley, magnifier, tool pouch.
- **Submission signature:** `capsule`, illustrated as a parcel entering a local receiving tray. Waiting workers hold a routing card; failed/lost states become still, attentive poses with the shared clear label.
- **Candidate public description:** “An extraordinary crew keeps your work moving through a lively dispatch depot.”

## Art handoff, review and acceptance

1. Artist starts with a six-silhouette sheet, environment composition, swatches and explicit influence/difference notes. Internal reference boards can name sources; retain references privately as appropriate, not copied media in shipped assets.
2. Review scene with real actor hit boxes, labels and office markers overlaid before final detailing. Check six stations are independently readable in Full/Quiet/Still and grayscale.
3. Produce editable originals and export passive SVG through the shared build gate. Supply manifest entries with creator, date, tool, input references, license/ownership evidence and output hashes. Copied references are not production assets.
4. Run every pack through the same semantic contact-sheet fixture, keyboard/list browser checks, contrast check and size/motion budgets. Review at scene size; a beautiful enlarged character sheet alone is insufficient.
5. Record original naming/art assessment, any licensed material, intended distribution and approved optional influence text. Resolve actual concerns for that pack; don't require new blanket permission merely for generic genre influence. Engineering validates record completeness, not legal sufficiency.
6. Release only the reviewed asset hash/version bundle. A complete launch means fifteen eligible packs plus Plain Floor. A phased pilot can ship fewer, with remaining concepts accurately marked unavailable.

All names, palettes, cast details and public descriptions are proposed design choices. The intent is vivid recognizable influence plus an original product identity, not one-for-one character substitutes disguised by new names.
